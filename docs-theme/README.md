# Contao documentation theme

These Jinja overrides extend MkDocs' built-in theme. `main.html` replaces the crowded horizontal navigation with a documentation sidebar and page contents, and removes linear previous/next links. Styling is in `docs/assets/contao.css`.

The unchanged corporate logo in `docs/assets/contao-logo.svg` comes from [Contao's official website](https://contao.org/files/contao/logo/contao-logo-corporate.svg). The orange `#f47c00` is taken from that SVG. The logo belongs to the Contao project.
